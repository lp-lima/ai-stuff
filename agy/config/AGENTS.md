# Regras Globais do Git

- Os commits sempre têm que ser assinados.
- NUNCA dispare a assinatura de um commit de dentro de uma conversa (evita bagunçar a UI com prompts do GPG).
- Sempre VALIDE se a assinatura de commits está pronta antes de executar um comando de commit.

# Idioma

- SEMPRE responda no idioma em que o prompt do usuário foi escrito.

# Local de Repositórios

- Novos repositórios (ou projetos git) devem ser criados sempre na pasta `/mnt/c/Users/lplim/repos`.
- Sempre publique novos repositórios no GitHub e garanta que eles tenham uma descrição apropriada configurada no repositório remoto.
